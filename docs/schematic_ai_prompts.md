# 电路原理图 PDF → AI 文本化描述 Prompt 手册

> **用途**：将图形格式的电路原理图 PDF，通过多模态 AI（Claude / GPT-4V 等）转换为结构化纯文本，供后续 AI 分析使用，降低 token 消耗。
>
> **使用流程**：PDF → 光栅化为图片 → 选择下方对应 Prompt → 送入多模态 AI → 保存输出文本

---

## 前置步骤：PDF 转图片

在送给 AI 之前，先将 PDF 页面转为高清图片：

```bash
# 200 DPI（推荐，平衡质量与 token 消耗）
pdftoppm -jpeg -r 200 -f 1 -l 1 schematic.pdf /tmp/page

# 300 DPI（密集原理图，元件标注多时使用）
pdftoppm -jpeg -r 300 -f 1 -l 1 schematic.pdf /tmp/page

# 批量转换所有页
pdftoppm -jpeg -r 200 schematic.pdf /tmp/page
# 输出文件：/tmp/page-01.jpg, /tmp/page-02.jpg ...
```

**Token 消耗参考：**

| 分辨率 | 约 tokens/页 | 适用场景 |
|--------|-------------|----------|
| 150 DPI | ~1,600 | 简单电路，元件少 |
| 200 DPI | ~2,500 | 通用推荐 |
| 300 DPI | ~4,000 | 密集图纸，精度优先 |

## Prompt 一：基础版（快速概览）

**适用场景**：快速了解电路功能，不需要完整网络表。

```
你是一名电子工程师。请分析这张电路原理图，用结构化文本描述其内容。

输出格式如下：

## 电路概述
[一句话说明电路功能]

## 元件清单
| 编号 | 类型 | 型号/参数 | 备注 |
|------|------|-----------|------|

## 网络连接
以"信号名: 元件引脚 → 元件引脚"的格式逐条列出每条网络：
- VCC: U1.VCC → C1.+ → C2.+ → R1.1
- GND: U1.GND → C1.- → C2.-
...

## 功能模块划分
[按电路功能分区描述，如：电源模块、主控模块、通信模块等]
```

## Prompt 二：精确版（用于后续 AI 深度分析）

**适用场景**：需要将输出文本交给其他 AI 做深度分析、问题排查、BOM 整理等。

```
你是一名资深硬件工程师，擅长阅读电子电路原理图。

请仔细分析上传的原理图图片，按以下结构输出完整的文本化描述。
要求：精确、完整，不要遗漏任何元件和连接关系。

---

# 电路原理图文本化描述

## 1. 电路总体功能
[描述该电路的用途和核心功能]

## 2. 元件清单（BOM）
| 位号 | 元件类型 | 型号或参数值 | 封装 | 数量 | 功能说明 |
|------|----------|-------------|------|------|----------|

## 3. 电源网络
列出所有电源轨：
- 电源名称：电压值，来源，供电对象

## 4. 网络连接表（Netlist）
格式：网络名 → [元件位号.引脚名, ...]
逐条列出每条信号线的所有连接点：

NET_NAME: U1.PIN_NAME, R1.1, C1.+, ...

## 5. 功能模块描述
按功能区域分别描述，每个模块包含：
- 模块名称
- 包含元件
- 工作原理简述
- 与其他模块的接口信号

## 6. 接口与连接器
列出所有对外接口（连接器、测试点、跳线等）：
- 位号、引脚数、每引脚定义

## 7. 注意事项 / 特殊设计
[如有特殊电路设计、保护电路、关键时序要求等，在此说明]

---

如果图片中某些文字因分辨率原因无法确认，请用 [?] 标注，不要猜测。
```

## Prompt 三：多页图纸版（单页处理）

**适用场景**：原理图有多张图纸，逐页处理后再汇总。每次送入一页图片时使用此 Prompt，替换 `{PAGE_NUM}` / `{TOTAL_PAGES}` / `{SHEET_NAME}`。

```
你是一名电子工程师，正在处理一套多页电路原理图的第 {PAGE_NUM} 页，共 {TOTAL_PAGES} 页。
本页图纸名称：{SHEET_NAME}（如已知）

请按以下格式输出本页的结构化描述：

# 第{PAGE_NUM}页：{SHEET_NAME}

## 本页元件
| 位号 | 类型 | 参数 | 说明 |
|------|------|------|------|

## 本页网络连接
逐条列出本页所有信号线及其连接点：
- 信号名: 元件位号.引脚 → 元件位号.引脚

## 页间接口信号（离页连接符）
列出本页所有离页连接符（off-page connector / port）：
- 信号名 | 方向（输入/输出/双向）| 目标页（如有标注）

---

如果图片中某些文字因分辨率原因无法确认，请用 [?] 标注，不要猜测。
```

---

## Prompt 四：多页汇总版（所有页处理完后使用）

**适用场景**：将 Prompt 三的所有输出拼接后，送入此 Prompt 进行跨页汇总。

```
以上是一套原理图所有页的文本化描述。

请完成以下汇总：

## 全局网络索引
将所有页中出现的离页信号汇总，列出每个信号在哪些页出现：
- 信号名：第X页(方向) → 第Y页(方向)

## 完整 BOM（去重合并）
合并所有页的元件，相同位号只出现一次，输出完整 BOM 表格：
| 位号 | 元件类型 | 型号/参数 | 封装 | 功能说明 |
|------|----------|-----------|------|----------|

## 系统架构总结
用自然语言描述整套电路的系统架构，包含：
- 核心芯片及其作用
- 各功能模块及互联关系
- 电源树结构
- 对外接口汇总
```

## 附录：常见问题与对策

| 问题 | 原因 | 对策 |
|------|------|------|
| 元件编号识别错误 | 图片分辨率不足 | 提升至 300 DPI 重新转换 |
| 连接关系遗漏 | 线路交叉复杂 | 将图纸局部裁剪后分块送入 |
| 引脚名称 [?] 标注过多 | 字体过小或模糊 | 用图像编辑器放大关键区域后重新识别 |
| 多页信号跨页对不上 | 离页符标注不清晰 | 在 Prompt 三中补充说明已知的跨页信号名 |
| AI 输出格式不稳定 | 模型遵循度不足 | 在 Prompt 前加：`严格按照以下格式输出，不要添加任何额外说明。` |
